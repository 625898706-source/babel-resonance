# 《明日方舟》奎隆·摩诃萨埵权化 — 美术与演出资料简报

> 供「英语学习 × 集成战略」Phaser 3 Roguelike 的 BOSS 专属战斗皮肤（战斗页视觉外观）使用。
> 标注规则：【查到】= 有来源；【实测】= 我从官方素材图直接取色/看图得出；【推测】= 我的判断。

## ① 奎隆是什么（含出处）

**【查到】**
- 全名：**奎隆，摩诃萨埵权化** / EN: **Qui'lon, Avatar of the Mahasattva** / JP: **「摩訶薩の権化」クイロン** / 韩: 콜람, 마하사트바의 권화。内部代号 `enemy_2089_skzjkl`，敌方编号 **QLN**，种族「萨卡兹」，地位「领袖」。
- 所属玩法：**集成战略 #5「萨卡兹的无终奇语」**（EN: *Sarkaz's Furnaceside Fables*，JP: サルカズの炉辺奇談），**内容拓展·一（Expansion I）** 加入。国服拓展一 2024/10/23；国际服 2025/04/24。
- 出场关卡两张：
  1. **ISW-DF 授法**（EN: *The Dharma Sermon*），6F「枷锁破碎之庙 / Temple of Shattered Shackles」——**内容拓展一的替补 6F 险路恶敌**，奎隆作最终 BOSS。
  2. **ISW-DF 不容拒绝**（EN: *Fate's Finale*），「无尽安眠 / Endless Rest」——内容拓展二五结局；需持有藏品 **「终末的现实 / Reality of The End」** 才会在第一区域刷出奎隆（那里他是削弱版：25 万血、限「自在阶段」、仅会【惩五戒】）。
- 数值（授法）：HP 300000 / ATK 1800 / DEF 2000 / RES 75 / 移速 0.5 / 攻击间隔 5.0 / 重量 9 / 扣 30 生命点。**短路径是史上最短的 BOSS 路线之一**。
- 背景：萨卡兹**第四任魔王**、第一位继承「黑冠」（文明的存续 / Civilight Eterna）的混血萨卡兹，称号「**游荡的霸主 / The Errant Overlord**」「**开明的暴君 / The Enlightened Despot**」「**最初的鬼 / The First Oni**」。武器「**怒涛青焰 / Wrathful Cerulean Flame**」——黑色长剑，缠绕蔚蓝源石技艺火焰，铭刻古萨卡兹语「**此处争斗止息**」。本尊已死；拓展一里的他是**平行历史中证悟成佛（阿纳萨 / Anasa）的版本**。英文名取自印度城市 Kollam（旧名 Quilon）。

**三阶段（演出骨架，皮肤可分阶段变奏）**【查到】
| 中文 | 英文 | 时长/触发 |
|---|---|---|
| **入定阶段** | State of Samadhi | 开局，无敌、自缚、不攻击、不可阻挡，盘腿打坐 |
| **自在阶段** | State of Vimutti | 入定 95 秒后转入；开始近战；每掉 25% 血强制【承三身】 |
| **无忧觉阶段** | State of Ashoka | 首次被击倒 → 7.33 秒重生 → 【棒喝】清场 → **战场切到第二张地图** |

技能名对照（中/英/梵语义）【查到】：
不着相 Tathata｜呼吸法 Anapanasati｜清火执 Quenching the Three Fires｜**怒目 Wrathful Gaze**（金刚怒目）｜惩五戒 Breaching of the Five Precepts｜**承三身 Trikaya**（召唤「托生莲座 Padmasana of Rebirth」）｜**棒喝 Upaya**（善巧方便）｜菩萨辩 Debate of the Bodhisattvas。

## ② 视觉描述

**【实测】头像 / 立绘特征**（来自 PRTS 官方敌人头像 `头像_敌人_奎隆，摩诃萨埵权化.png` 与 closure.wiki Spine 缩略图）：
- **银白色巨量鬃毛/长发**，蓬松外扩，占画面比例极大 —— 这是第一识别点。
- **脸/头冠为一枚鲜红-朱红的火焰形造物**，像燃烧的冠冕罩住上半张脸（对应「怒涛青焰」与「怒目」）。
- 身体：**白/象牙色基底的华服**，胸腹有**华丽银白浮雕护甲/珠宝**质感；**深灰近黑的护手与甲片**；**深酒红（绯红）披挂/围巾**。
- 画面左侧有一条**巨大的弧线金色环状物**（金铜色、带蛇/龙形端头）—— 与立绘背后的**背光光环/金轮**元素一致。
- 腰际/左侧垂挂**成串的串珠（念珠）状饰物**。
- 体型：直立人形，修长但不魁梧，姿态沉静。

**【实测】金轮 = 宝轮「文明的存续」**：官方敌人描述明确写「**『文明的存续』为其宝轮，破碎的利剑为其法门**」（EN: His *Cakraratna* is Civilight Eterna, and his *Dharmaparaya* is a shattered sword）。宝轮（Cakraratna）即转轮圣王之轮宝 → 背后的环形/光轮是**宗教义理必需的符号**，不是随意的装饰。【推测】这也是皮肤最该保留的构图锚点。

**【实测】配色实测（从官方素材直接统计像素，非官方发布值）**：
- 立绘饱和度最高的色簇：`#3C0C24`（暗酒红/近黑紫红）、`#542424`、`#6C2424`、`#9C3C3C`、`#B43C3C`、`#843C24`、`#6C3C24`、`#CC543C`（亮朱红高光）
- 中性主色簇：`#080808`（黑）、`#282828`、`#282838`/`#181828`（**冷灰蓝黑**，带蓝调，不是纯灰）、`#B8B8B8`、`#B8B8C8`（**冷调银**）、`#F8F8F8`（象牙白）
- 金件（低饱和暖调簇）：`#B4B49C`、`#786858`、`#846C54`、`#9C846C` → **褪色古铜金**，不是明亮黄金

**【实测】战斗场地（6F 枷锁破碎之庙，拆包地图）**：
- 俯瞰式**南亚/东南亚佛教石构神庙废墟**：中轴对称的**多级阶梯平台**，四周是**深灰绿积水的庭院**，水面漂着**成片荷叶**，边缘有**台阶与护栏**，点缀**深绿灌木与暖橙色灌木**。
- 地面几乎每格都铺**方形曼荼罗/坛城式金线纹样地砖**。
- 整体：**冷灰石灰岩 + 苔绿 + 暗水 + 极少量金色纹样 + 少量暖橙植被**。光照是**低对比散射天光**，雾气压暗远景。
- 第二张「无忧觉」地图：同一套建筑语言，但按 PRTS 截图与机制（阵雷、决战）应更暗、更空旷。【推测】

**出场演出**【查到机制，【推测】演出形式】：
开局即**入定盘坐 + 长时间无敌**（95 秒），身上不断放【呼吸法】召唤尼卢火，地图上雷击不断。**首次死亡不是终点**：7.33 秒重生 → 【棒喝】清空全场敌我单位 → 闪现 → **战场地图整体切换**。皮肤可以把这条「入定 → 开眼 → 涅槃」的节奏做成三套状态视觉。

**音乐【查到】**：
- 曲名 **《舍盘持难题纳婆罗为谛》**，英文标注 **Srávantī́ Tnadi na Brávīti**，官方给的梵语含义是「**A River of Flowing Words**」（言词之流 / 流言之河）。作曲 **Steven Grove**，时长 3:04（BGM 版 245 秒）。
- **关键：该曲在游戏内的用途栏只写着「The Dharma Sermon」** —— 即**这就是奎隆 BOSS 战的专属 BGM**，不是通用曲。
- 【实测】它是本主题 12 首里**唯一用梵语/经文式命名**的曲目；同主题其他 BOSS 曲用的是萨卡兹语命名（Nar'aejeph Saralteri = No Alternatives、Sura Saraǧul'tee = Arise My Friends）。这坐实了「奎隆线 = 印度/佛教语汇」这一美术总方向。
- 6F 场景曲另有一首 **Steadly Unfolds the City of Souls**（6F Temple of Shattered Shackles / Bizarre Fragment）。
- 氛围【推测】：梵语诵经式人声 + 仪式感打击 + 电子低音，庄严肃穆、缓慢压迫、有「说法/辩论」而非「咆哮」的气质。**不是热血战歌**。

## ③ 萨卡兹肉鸽美术风格

**【查到，来源：机核《洞穴时代与内陆帝国：萨卡兹们的精神世界》】** —— 这是目前所见最靠谱的中文设计分析：
- **主题内核**：荣格的「**集体无意识**」+ 记忆宫殿 + 大卫·林奇《内陆帝国》。整个肉鸽是「死魂灵的虚构历史 / 族群自我疗伤」。
- **两条设计路径**：① 表现主义→抽象表现主义（心理侧写、梦境、冥想）；② **立体主义**（时间的重叠、过去与现在的融合）。
- **具体手法**：「印象重建 / Impression Restoration」用**色块喷溅（splatter）**造不规则边缘 + **雾状晕染**背景 + **前景缺损石板蒙版**，正负空间互为符号（例：「侵略」石板用大量红色强调攻击性，负空间切出三个长角的人）。
- **核心纹样 = 拱门**：「在整个萨卡兹的符号设计中，**拱门**这个元素是重复次数最多的」。每层过场背景都是拱门，险路恶敌下方是拱门。形制是**标准的半圆拱（Roman / Byzantine / Romanesque 系）**。次要构件是**柱**。特殊敌人叫「门」与「窗」——建筑构件直接被符号化。
- **宗教/密宗/曼荼罗元素**：**主萨卡兹肉鸽整体不是密宗曼荼罗路线**（那是奎隆这条支线才引入的）——这是关键区分。【推测】奎隆战是**在萨卡兹「拱门 + 表现主义喷溅」的底盘上，叠加一层印度/佛教图像**：宝轮、莲花（托生莲座 Padmasana）、坛城式地砖、梵语咒名。别把整张战斗页做成通用曼荼罗，那会丢掉萨卡兹的血统。

**【查到的萨卡兹肉鸽 UI 特征】**：节点可刷新、有「散佚思绪/印象重建/巫仪档案库/历史重构」等石板与档案式界面；UI 在玩家社区里被评价为「游戏内和网站 UI 美术都好棒」。**注意：我没查到官方发布的 UI 设计规范或字体名。**

## ④ 配色建议

**【实测】底色/中性（取自官方立绘像素统计）**
| 用途 | Hex | 说明 |
|---|---|---|
| 最深底 | `#080808` | 近纯黑，用于最深处/描边 |
| 冷灰蓝黑 | `#282838` / `#181828` | **带蓝调的深灰**，立绘甲片主色。用它而不是纯灰做暗部，能立刻出「方舟味」 |
| 中灰 | `#484848` / `#383838` | 场地石材（地图实测主色 `#383838` 18.2%、`#282828` 16.5%、`#484848` 11.2%） |
| 冷银 | `#B8B8C8` / `#B8B8B8` | 银白鬃毛、银饰 |
| 象牙白 | `#F8F8F8` | 最高光/华服 |

**【实测】强调色**
| 用途 | Hex | 说明 |
|---|---|---|
| 主强调·朱红 | `#CC543C` | 立绘亮红高光，火焰冠 |
| 强调·绯红 | `#B43C3C` | |
| 强调·深酒红 | `#6C2424` / `#542424` | 披挂/暗红布料 |
| 极暗紫红 | `#3C0C24` | 阴影里的红，避免红色过艳 |
| 金件 | `#B4B49C` → `#9C846C` → `#846C54` | **褪色古铜金**，做金轮/金线纹样。**不要用 #FFD700 那种亮金** |

**【查到】官方 UI 红（可直接用于皮肤框体/标题）**
- `#C01D22` —— PRTS 敌方信息表头背景色，是方舟**敌方/BOSS 语义的官方红**。
- `#B7301E` —— arknights.wiki.gg 关卡信息框边框红。
- `#FF4F08` / `#FF4F0B` / `#FF4C22` —— 官方游戏内**阶段名/危险提示的橙红文字色**（数值取自 wiki 表格 class 与 PRTS 内联样式）。**这三个是现成的「BOSS 阶段标签」色，可以直接抄。**

**【实测】场地环境色**
- 苔绿/橄榄：`#54543C`、`#686858`、`#485848`
- 石与暖植被：`#9C846C`、`#84846C`、`#845454`、`#6C3C3C`
- 暖橙（BOSS 头像底板）：`#E48424` / `#B45424` / `#6C3C24`

**【推测】推荐战斗页配色方案（3 色 + 2 辅）**
- 背景底 `#1A1A22`（冷蓝黑）→ 场地下半部渐变压暗
- 建筑/石板 `#484848` → `#282838`
- 主强调（奎隆/危险）`#CC543C`
- 副强调（佛光/宝轮/纹样）`#9C846C`（褪色金），发光时提到 `#B4B49C`
- 语义红（阶段标签/血条）`#C01D22`，阶段切换闪 `#FF4F08`
- 玩家/我方安全色保持中性青白，避免与朱红撞色

**给皮肤的落地建议（【推测】）**
- 保留三件套：**银白鬃毛体量感 + 朱红火焰冠 + 背后金轮**。少任何一件都会不像奎隆。
- 底色走**冷灰蓝黑**（`#282838` 系）而不是暖黑，这是方舟敌方的通用暗部语言。
- 金色只用**褪色古铜金**（`#9C846C`），对比度靠**朱红 `#CC543C`** 和**银白 `#B8B8C8`** 撑，不要靠亮金。
- 阶段切换用官方橙红 `#FF4F08` 做瞬时闪色，稳定态用官方红 `#C01D22` —— 这两个色**游戏里就是这么用的**，玩家会认。
- 若要体现「授法 / 辩论」而非「蛮力」，把动效做成**缓慢、对称、仪式化**的（坛城式地砖逐格点亮、金轮旋转、雷击预告高亮），而不是爆炸粒子。
