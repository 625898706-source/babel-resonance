方案 D · 刻度尺（竖向刻度骨架）

最左一根**竖向刻度尺**（每 28px 一个 tick，每 5 格加长），所有内容挂在刻度上 —— 档案馆／建筑图纸的味道，和"语域、残响、记录"的世界观最贴。列表用同一条刻度统一分隔，天然整齐。
可行性：刻度尺＝1×s 矩形若干（或一个 Graphics 循环画线 ✓）✓ 内容挂轴＝坐标控制 ✓ 零新依赖 ✓
实现方式（全部能在 Phaser 里原样复现）：纸白底＝矩形；所有分隔/主轴/刻度＝1×s 矩形（或 Graphics 画线）；卡片＝矩形 fill/stroke；文字＝项目自带字体（中文 HarmonyOS、英文 Space Grotesk、小标签 Novecento Wide）；强调＝唯一红 #e2231a；需要柔和过渡时才用运行期 canvas 贴图。未使用任何我实现不了的手法（无 CSS 阴影模糊、无渐变边框、无图标字体、无 SVG 装饰、无 backdrop-filter）。每个 stage 都是 1280×720＝游戏逻辑分辨率，坐标与字号可直接搬进代码。
