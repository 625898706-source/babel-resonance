玩法：先许愿（小／中／大三档 ✓ 愿望越大、句子越绕 ✓）→ 判断**划线部分在句中作什么成分**（固定 7 个标签 ✓ 每题从中抽 4 个做选项 ✓）→ 判对＝全额兑现 ✓ 判错＝降一档兑现 ✓
三档只差句子结构：小份＝简单句 ✓ 中份＝简单主从复合句（划线＝一个从句 ✓ 但答案仍是那 7 个之一 ✓）✓ 大份＝复杂主从复合句（要穿过嵌套才判得出 ✓）
可行性（全部可 100% 复现）：句子＝项目字体文字 ✓ 划线加粗＝把句子拆成**三段文字**（前段／划线／后段 ✓ 先建后量宽再整行居中 ✓ 与失与得里“它”红字同一手法 ✓）✓ 下方红线＝2×s 矩形 ✓ 选项＝文字 + 1×s 发丝线 ✓ 悬停变红＝自绘线的 setFillStyle ✓ —— 没有用任何实现不了的效果 ✗
硬约束：句子必须**排在一行**（折行后跨行划线做不出来 ✗）→ 故大份词数上限 24 词 ✓ 字号按长度自适应（20~26×s ✓）
