# 二层「残响之隙」BOSS 机制方案（3 个方向）

> 现状：`FLOORS[1].combat.types.rare` 目前挂的是**里恩（一层机制）作占位**。
> 本方案给二层专属 BOSS；里恩保留在一层（用户已确认里恩可同时存在于两层）。
> 所有方向都遵守 §17 硬约束：独立定义在 `combat.types`、不改其它战斗共用路径、E3 视觉 + `s` 缩放 + 中栏 `cx±340`。

## 方向 A · 回响者 · 厄科（**记忆回响 / 中→英反向**）★ 推荐

| 字段 | 内容 |
|---|---|
| **名称** | 回响者 · 厄科（Echo, the Resonant） |
| **一句话体验** | 「你在跟自己的记忆打架——它把你这一局答过的词原样丢回来，还要你从中文倒推英文。」 |
| **触发** | 二层 `rare` 节点（残响之隙） |
| **玩家的决策** | 一阶段考"复习"（认出答过的词）；二阶段**只给中文释义，从 4 个英文单词里选**（产出型，比"认出"难一档）。玩家要判断：是凭记忆赌，还是用构词法推 |
| **英语学习点** | **主动回忆（production）+ 已学词巩固**；利用 `RunState.usedWords`（本局已答词）出题 → 天然形成"复习闭环"，这是别的战斗做不到的 |
| **数值** | HP 26 / 攻击 2 / phase1 倒计时 14s、phase2 12s / `phase2Hp: 13`（HP≤13 进二阶段） |
| **失败代价** | 答错 → 该词进入**「回响」区**（右侧胶囊累加）；**累计 3 个回响 → BOSS 回复 4 HP 并清空回响**（惩罚是"记忆债"，不是单纯扣血） |
| **反馈** | 答对：卡片中心扩散一圈**回声涟漪**（复用 `fire-glow` 贴图放大淡出）；答错：该词以**半透明残影**从卡片飘回敌方立绘（Text + tween） |
| **系统耦合** | `迅捷之羽` 影响倒计时 ✓、`凝视之瞳` 排除选项 ✓；可加新藏品「回响之环」（每清空一次回响，本场伤害 +1） |
| **落地成本** | **中**（一阶段复用现有 4 选 1，只是词取自 `usedWords`；二阶段把选项文本换成英文单词；回响胶囊用现成 `chip()`；涟漪用现成贴图）**无需新贴图/音频** |
| **风险** | ① 本局 `usedWords` 太小时无词可出 → 兜底：不足 N 个时从一层词库补足；② 二阶段"中→英"对基础弱的玩家偏难 → 给 4 个选项里放 1 个明显无关项降低难度 |

**立绘建议**：需要一张新立绘（webm → 精灵图，流程见 skill §9）；主题＝"戴着回声面具的人形"，可用镜像双影效果（同精灵图叠两层，一层低透明 + 水平偏移）。

## 方向 B · 词族 · 三连回响（**词形变化 / 快节奏三连**）

| 字段 | 内容 |
|---|---|
| **名称** | 词族 · 三连回响（Word-Family Triple） |
| **一句话体验** | 「像打节拍：一个词族的三道快题一口气打完，断一拍就全废。」 |
| **触发** | 二层 `rare` 节点 |
| **玩家的决策** | 每题只有一个空，但四个选项是**同一个词族的不同词形**（decide / decision / decisive / decisively）→ 玩家必须判断"这里要什么词性"，而不是"这个词什么意思" |
| **英语学习点** | **词族 / 词性 / 构词法**（高中英语核心考点，**现有机制完全没考**） |
| **数值** | HP 24 / 每题 6s × 3 连 / 攻击 2；完整三连造成 **6 点伤害**（分段结算，每连对 2 点） |
| **失败代价** | 任一题答错或超时 → 本回合**作废**，且 BOSS 立刻反击：**下一回合每题时间 −1s**（可叠加，压迫感） |
| **反馈** | 卡内 **3 格进度点**（复用 `pips(sz,3)`）：每连对亮 1 格；三连成功 → 三格同时变红 + **屏震** + 一道横扫光带 |
| **系统耦合** | 与藏品 `破环之诫`（连续答对加成）天然契合；三连视为"连续答对 3 次" |
| **落地成本** | **中**（核心成本是**词族数据表**：需从 GAOKAO 词库人工整理 ~30 组「decide→decision→decisive」；渲染复用 4 选 1） |
| **风险** | ① 词族数据质量决定体验，必须人工校对；② 6s 快节奏对手速有要求，可能需要 8s |

## 方向 C · 静默回响（**字母逐个消散 / 视觉记忆**）

| 字段 | 内容 |
|---|---|
| **名称** | 静默回响（Silent Echo） |
| **一句话体验** | 「词只出现一瞬，然后字母一个个被黑暗吃掉；你要在它彻底消失前把答案钉下去。」 |
| **触发** | 二层 `rare` 节点 |
| **玩家的决策** | 题目显示 1.2s 后，字母**从右往左逐个消失**（每 0.6s 消失 1 个）→ 玩家必须决定：先记住整体长度与首尾字母，还是赌自己熟悉这个词（早答 vs 多看一眼） |
| **英语学习点** | **拼写结构记忆**（字母顺序、词长、常见词缀 -tion/-ment/-less） |
| **数值** | HP 22 / 攻击 2 / 每题：显示 1.2s → 每 0.6s 消散 1 个字母 / 共 4 题；全部消散后再给 3s 缓冲 |
| **失败代价** | 字母全消散 + 3s 内未答 → 判超时（扣血）；答错 → 不额外惩罚（时间压力已足够），直接进下一题 |
| **反馈** | 字母消散时留 **0.3s 余像**（半透明残影后淡出，复用残影 tween）；倒计时条转暗红（`cdBar.setColor(0x9e1207)`）；消散完有一次"空响"屏震 |
| **系统耦合** | 可与二阶段叠加（phase1 正常显示 → phase2 才消散），降低上手门槛 |
| **落地成本** | **小~中**（纯逻辑：用逐字母 Text 或按切片 `setText`；无需新素材） |
| **风险** | **公平性**——对不熟悉该词的玩家过于硬核；必须做成"二阶段才消散"或给"看一次完整词"的藏品道具 |

## 方向 D · 双声 · 交替敲击（**备用，成本大**）

屏幕**同时给出左右两道题**，BOSS 交替"敲"某一侧（被敲的一侧才开始倒计时），只能答被敲的那侧。考**注意力切换**。
**为什么列为备用**：① 与"中栏 `cx±340*s`"宽度纪律冲突（两张卡放不下），需改成上下分屏；② 垂直空间紧张（页眉 52 + 两卡 + 选项 + 底栏）；③ 实现成本**大**。→ 建议二层先做 A/B/C 中之一，D 留给三层。

## 推荐与理由

**推荐方向 A（回响者 · 厄科）**：
1. **主题最贴**：「残响」＝回声，而"把你答过的词丢回来"就是字面意义的回响；
2. **唯一利用 `usedWords` 的机制**：把"肉鸽的一局"变成"英语复习闭环"，与本作"学习游戏"的定位强绑定；
3. **成本可控**：不需要新贴图/音频，渲染全部复用现有组件；
4. **难度曲线自然**：一阶段复习（认）→ 二阶段产出（用），正好对应二层的强度。

**次选 B**：如果你更想要"考词形变化"的新题型（学习价值最高，但需要整理词族数据表）。
**C** 适合做成"某个 BOSS 的二阶段特殊状态"，而不是独立 BOSS（强度偏高、公平性风险）。
